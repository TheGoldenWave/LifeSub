# LifeSub / 旁白

LifeSub is a local-first personal memory system for capturing conversations and meetings, turning them into searchable memories, and making those memories available to AI agents with explicit privacy controls.

## Direction

- macOS menu bar capture for microphone and meeting audio
- Local ASR by default, with configurable cloud ASR and summary providers
- A shared local core used by the macOS app and agent integrations
- Native integrations for Codex, DeepSeek Harness, and Malow
- Tiered memory access: ordinary content may include transcripts, while sensitive content requires stricter access
- GitHub-based synchronization for readable summaries and encrypted sensitive records; raw audio remains local by default

## Status

LifeSub is currently in product and architecture design. The first milestone is a software-only, local-first memory retrieval loop before wearable hardware development.
