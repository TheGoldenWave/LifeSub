# 产品定义

## 一句话定位

LifeSub（旁白）是一个本地优先的个人 AI 记忆系统：记录会议与重要对话，自动转写和理解，并让获得授权的 Agent 能够检索带来源证据的个人记忆。

## 背景

目前没有一款开箱即用的消费级产品同时完整覆盖：

1. 全天候或低打扰的随身录音。
2. 视频会议系统音频内录。
3. 自动 ASR、摘要、检索和证据回溯。
4. 本地优先的数据控制。
5. 可被不同 Agent 产品复用的标准化记忆能力。

现有产品通常只解决其中一段链路：可穿戴设备擅长采集，会议机器人擅长会议转写，录音笔擅长中文 ASR，但用户的数据、权限和记忆检索仍被分散在不同产品中。

## 产品愿景

LifeSub 最终由四层组成：

- 可穿戴录音硬件：低功耗、明确提示、长续航的日常音频入口。
- 桌面与移动伴侣：录制、同步、查看、编辑和权限管理。
- LifeSub Core：个人记忆的处理、存储、检索、同步与审计核心。
- Agent 插件生态：Codex、DeepSeek Harness、Malow 及其他 Agent 的原生入口。

首版不同时启动全部四层。当前策略是软件先行，先验证“记录 -> 理解 -> 记忆 -> Agent 回忆”的闭环，再进入硬件研发。

## 首版目标

首版聚焦 macOS，完成以下主链路：

1. 用户从菜单栏开始一次会议记录。
2. LifeSub 分别采集系统音频和麦克风音频。
3. 本地 ASR 默认完成转写，也允许用户显式选择云端 ASR。
4. 可配置的模型生成结构化摘要与记忆条目。
5. LifeSub 为每条记忆保存时间、来源、原文证据、处理模型和敏感级别。
6. Codex、DeepSeek Harness 或 Malow 通过插件查询个人记忆。
7. 用户可以从 Agent 返回的记忆回到原始时间点和文字证据。

音频文件导入作为补录与调试入口保留，但不是首版的主体验。

## 首版非目标

- 全天候持续录音。
- 自研可穿戴硬件。
- iOS、Android 和 Windows 客户端。
- 实时把谈话内容持续注入 Agent。
- 让 Agent 控制开始或停止录音。
- 公网托管的个人记忆服务。
- 多人团队知识库和企业权限体系。

这些方向可以进入后续阶段，但不应拖慢首个个人记忆检索闭环。

## 核心用户价值

- 回忆：找回“什么时候讨论过、做了什么决定、当时原话是什么”。
- 连续性：让不同 Agent 共享同一份经过授权的个人上下文。
- 可信度：摘要始终可以追溯到来源、时间点和原文证据。
- 控制权：音频和核心数据默认留在本地，外发行为清晰可见。
- 可迁移性：记忆采用开放格式和通用接口，不锁定单一 Agent 或模型。

## 生态定位

LifeSub 由 goldenwave 与 Malow 产品协同打造，是 Malow 生态的一部分，同时保持独立的本地核心和开放适配层。Malow 可以提供完整产品体验，其他 Agent 则通过 MCP 或宿主原生插件使用同一套记忆能力。

## 成功标准（草案）

正式指标仍待确认，首轮验证至少应回答：

- 一次会议从停止录制到可检索记忆，是否能在可接受时间内完成。
- 中文会议转写是否足以支持准确的主题、决定和行动项提取。
- Agent 是否能稳定找到正确记忆并给出可验证的来源。
- 用户是否能理解每次模型调用的数据去向。
- GitHub 同步是否能在不暴露敏感内容的前提下完成多设备迁移与灾备。
