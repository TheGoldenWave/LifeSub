## 本版改进

- 设置整合为录音、ASR 与模型、诊断三个入口，准备状态只展示当前已有证据。
- 麦克风首帧测试显示设备类型和测试时间；设备断开或选择变化后，旧测试结论立即失效。
- 模型安装展示下载、校验、安装和运行时验证阶段；时间线展示已持久化的转写 Job 状态。
- 诊断可复制设备、错误与运行时候选身份，并对选中麦克风重新测试；可选未安装模型不再被当作必修故障。
- 桌面转写的说话人来源只读显示，临时润色明确标记为页面预览。

## 已完成验证

- Rust Tier 2/Tier 3、Swift、前端测试与浏览器回归通过。
- SenseVoice 与 Whisper 固定样本在候选 Gate 下两轮通过；诊断大目录与启动窗口基线见 [0.2.2 性能基线](https://github.com/TheGoldenWave/LifeSub/blob/main/docs/performance/lifesub-0.2.2-baseline.md)。
- DMG 镜像、arm64 架构、包内签名和构建/镜像二进制一致性通过。

- 配置 Developer ID Application 签名和 Apple 公证，重新生成面向其他 Mac 的分发包。
