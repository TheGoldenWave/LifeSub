# LifeSub V0.1 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a locally runnable macOS-first LifeSub application that supports capture-session control, audio import, immutable transcript revisions, timeline search, Evidence URI resolution, and Markdown export.

**Architecture:** A React/TypeScript desktop interface calls a Tauri command layer backed by a Rust Evidence Core and SQLite. Platform capture is isolated behind a narrow adapter; the first usable build includes a deterministic demo adapter and file import so the entire evidence workflow remains testable without signing or OS capture permissions.

**Tech Stack:** React 19, TypeScript, Vite, Vitest, Tauri 2, Rust 2024, rusqlite, serde, uuid, chrono, SHA-256.
