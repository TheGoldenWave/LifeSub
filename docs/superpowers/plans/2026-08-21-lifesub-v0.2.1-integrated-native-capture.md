# LifeSub V0.2.1 Integrated Native Capture Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver one signed V0.2.1 macOS app with the latest four-page UI, real ScreenCaptureKit/AVAudioEngine dual-source capture, immutable rolling audio chunks, real local ASR publication, and no desktop demo fallback.

**Architecture:** A signed Swift helper owns macOS capture APIs and Apple audio encoding. Rust launches/authenticates it through an inherited anonymous bootstrap pipe plus a private Unix socket, seals helper-produced chunks into the anchored store, and runs the existing fenced ASR pipeline with a production native executor. The functional worktree remains the integration base; behavior from `main` is ported selectively and proven by tests.

**Tech Stack:** Swift 6/SwiftPM, ScreenCaptureKit, AVFoundation/AVAudioEngine, Rust 2024, Tauri 2, rusqlite, sherpa-onnx 1.13.5, React 19, Vitest, Playwright.

**Specification:** `docs/superpowers/specs/2026-08-21-lifesub-v0.2.1-integrated-native-capture-design.md`
